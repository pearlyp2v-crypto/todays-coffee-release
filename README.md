# 오늘의 커피 · 배포용 실행본

현재 앱 버전: **v3.8.14**. 개발 원본은 `pearlyp2v-crypto/app-todays-coffee`에서 관리합니다. 이 저장소의 HTML을 직접 수정하지 않습니다.

- `index.html`: 검증된 단일 실행본.
- `release.json`: 원본 커밋과 HTML SHA256.
- `build-manifest.json`: 개발 빌드 입력/출력 해시.
- GitHub Pages 설정은 별도이며 저장소에 올렸다는 사실만으로 웹 배포 완료를 뜻하지 않습니다.
- 사용자 기록은 브라우저에 저장됩니다. 주소가 바뀌면 개인 백업 v1으로 이전하세요. 개인 백업 JSON은 이 저장소에 올리지 않습니다.

기본 기능은 데이터를 내장하며 OCR은 외부 Tesseract 로딩이 필요합니다. 모바일 실기기·전체 백업 사진 복원 회귀는 별도 검증 대상입니다.
